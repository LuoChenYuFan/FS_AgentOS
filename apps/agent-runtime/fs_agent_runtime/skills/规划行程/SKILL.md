# 规划行程

## 何时使用

用户要规划旅行、行程、攻略、一日游，或询问从哪里到哪里怎么走时使用本 Skill。

## 如何调用

参数用独立字段，不要放进嵌套对象：

```text
run_skill(name="规划行程", 起点="北京南站", 终点="故宫", 方式="公交")
run_skill(name="规划行程", 起点="上海虹桥站", 终点="外滩", 方式="驾车", 途经="静安寺")
run_skill(name="规划行程", 城市="杭州", 关键词="西湖", 天数="1")
```

`方式` 可以是驾车、步行、公交、骑行。没写时按驾车。`天数` 为 1 到 3。

## 返回

- `summary`：一段中文说明，包含地点、耗时、距离或推荐顺序。
- `itinerary`：城市、天数、出行方式和地点列表。
- `cost_estimate`：能从路线里读到的票价或过路费；没有则为 0。

## 约束

- 必须使用脚本返回的路线或地点，禁止编造耗时、距离、换乘或景点。
- 起点和终点都不明确、也没有城市时，先问用户从哪到哪，不要猜测。
- 不要把高德密钥写进对用户的回复。
