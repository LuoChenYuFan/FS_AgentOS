# 酒店查询

## 何时使用

用户询问某地酒店、住宿均价或某个星级的房价时使用本 Skill。

## 如何调用

```text
run_skill(name="查酒店", 城市="广州", 星级="5", 日期="明天")
```

- `城市` 用用户说的城市。
- `星级` 用数字。用户没说时不要自己挑一个星级。
- `日期` 用今天或明天。

## 返回

- `hotels`：酒店列表。
- `avg_price`：平均价格，单位元。和差旅标准比较时使用这个字段。
- `count`：查到的酒店数量。

## 约束

- 城市不明确时，先问用户，不要猜测。
- 当前脚本返回的是固定均价，还没有接入真实酒店接口。不要把这个数字说成实时房价。
