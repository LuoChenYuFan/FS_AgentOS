# 发送邮件

## 何时使用

用户要求发邮件、发信、把一句话通知给主人或老板时使用本 Skill。不要在只是聊天、查资料时调用。

## 如何调用

```text
run_skill(name="发邮件", 收件人="主人", 主题="调休通知", 正文="我明天调休一天")
run_skill(name="发邮件", 收件人="老板", 正文="会议改到下午三点")
```

收件人可以是白名单里的邮箱，或「主人」「东家」「老板」「张博洋」等称呼。称呼一律发到白名单邮箱。白名单以外的任何邮箱或称呼必须拒绝。

## 参数

- `收件人` / `to`：邮箱或主人称呼。空着时，若用户在说给主人发信，则使用白名单第一项。
- `主题` / `subject`：用户说了就用原话，否则用正文前若干字。
- `正文` / `body` / `正文模板`：用户要传达的内容。

## 约束

- 必须真正调用脚本。只有 `sent` 为 true 才能告诉用户已经发出。
- 禁止发到 `SMTP_WHITELIST` 以外的地址。拒绝时如实说明，不要改用其他邮箱重试。
- 不要把 SMTP 账号、授权码或白名单原文写进对用户的回复。
