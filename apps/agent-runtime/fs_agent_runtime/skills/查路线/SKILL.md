# 路线查询

## 何时使用

用户给出起点和终点，询问怎么走、打车、乘车或通勤路线时使用本 Skill。

## 如何调用

参数必须作为独立字段传入：

```text
run_skill(name="查路线", 起点="西直门地铁站", 终点="北京南站", 方式="乘车")
```

- `起点`、`终点` 用用户原话里的地点。
- `方式` 可以是驾车、步行、公交、地铁。没说时按乘车处理。

## 返回

- `duration_min`：耗时，单位分钟。
- `distance_km`：距离，单位公里。
- `steps`：分段说明。
- `fare`：费用，单位元。和差旅标准比较时使用这个字段。

## 约束

- 起点或终点不明确时，先问用户从哪到哪，不要猜测。
- 当前脚本返回的是固定的耗时、距离和费用，还没有接入真实地图。不要把这个数字说成实时路况。
