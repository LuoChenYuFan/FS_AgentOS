# 天气查询

## 何时使用

用户询问某地今天起 10 天内的天气、气温、降雨、湿度、风力，或做出行、穿衣相关的天气判断时使用本 Skill。

## 如何调用

先确认城市名，再执行。参数用独立字段，不要放进嵌套对象：

```text
run_skill(name="查天气", 城市="北京")
run_skill(name="查天气", 城市="上海", 日期="明天")
run_skill(name="查天气", 城市="北京", 日期="后天")
```

`城市` 支持中文或英文。日期按用户原话传入，例如「今天」「明天」「后天」「大后天」「3天后」「10月8日」。不要把后天改成今天。`上海`、`上海市`、`Shanghai` 视为同一地点。

## 返回

- `summary`：一段中文说明，包含地点、时段、天气、气温。
- `temp`：气温数字。今天用当前气温，之后的日期用最接近中午的预报气温。
- `condition`：天气描述，例如「晴」「多云」。

## 约束

- 必须使用脚本返回的实况或预报，禁止编造气温、天气或风力。
- 城市不明确时，先询问用户要查哪个城市，不要猜测。
- 只支持今天起 10 天。更远的日期要把「查询的时间比较长，暂时只支持查询10天内的天气情况」告诉用户，不要改成查今天，也不要用相同参数重试。
- 不要把 OpenWeather 密钥写进对用户的回复。
